# ԿԿՀ ռիսկերի վերլուծության մոդուլ — նախատիպ

Ցուցադրական նախատիպ՝ ըստ «Ֆունկցիոնալ պահանջների փաստաթղթի (SRS)» ([docs/](docs/))։
Իրական ինտեգրում EPD-ի և պետական շտեմարանների հետ չկա. օգտագործվում են mock տվյալներ
(EPD-ի տվյալների մոդելով և SRS 11.5-ի ծառայությունների կառուցվածքով)։

## Գործարկում

**Արագ տարբերակ (առանց սերվերի և ինտերնետի).** բացել `dist/index.html` ֆայլը բրաուզերում
(Chrome, Edge, Firefox)։ Ֆայլը ինքնաբավ է՝ JS, CSS և հայերեն տառատեսակը ներառված են։

**Աղբյուրից.** պահանջվում է Node.js 20+։

```bash
npm install
npm run dev       # մշակման ռեժիմ՝ http://localhost:5173
npm run build     # հավաքում է dist/index.html (մեկ ֆայլ)
npm test          # կանոնների շարժիչի թեստեր
npm run epd:schema  # EPD թեստային բազայի կառուցվածքի արտահանում (VPN, .env.local)
```

## Ինչպես ցուցադրել

1. **Վահանակ** — ռիսկային փաստաթղթերի քանակը ըստ ուղղությունների։ Սկզբում որոշ կանոններ «չի գնահատվել»
   վիճակում են, քանի որ դրանց փոփոխականների արժեքները SRS-ում տրված չեն։
2. **Փոփոխականներ → «Լրացնել ցուցադրական արժեքներ…»** (դեր՝ «Կանոնների պատասխանատու»). լրացնում է
   կենսաապահովման նվազագույն բյուջեն (Q-47 վարկածով՝ սպառողական զամբյուղի արժեքներով), նվերի անսովոր արժեքի
   բազմապատկիչը (5՝ SRS-ի օրինակից) և համեմատվող տարիների քանակը (3)։ Արժեքները նշված են որպես ցուցադրական։
3. **Հայտարարագրեր** — Տիգրան Մկրտչյան 2025 (բացասական ծախս), Դավիթ Գրիգորյան 2025 (տեխնիկական վրիպում.
   «Հայտարարագրի տվյալներ և ճշգրտումներ» ներդիրում ճշգրտեք կանխիկը 25 000 000 → 2 500 000, DEC-10)։
4. **Կուսակցություններ**, **Նվերների ձևաթղթեր**, **Բարեվարքություն** — ռիսկային նշումներ՝ արժեքներով (COM-19)։
5. **Արտաքին համակարգեր** — անջատեք ԲՊՌ-ն և տեսեք, որ PAR-R6-ը դառնում է «չի գնահատվել» (COM-17)։
   Մատյանում երևում է, որ հարցումներ կատարվում են միայն արտաքին տվյալ օգտագործող կանոնների համար (COM-14)։
6. **Կանոններ → Կառուցիչ** — «Լրացնել օրինակով», «Փորձարկել», «Պահպանել» (COM-01, COM-04, COM-05)։
7. Վերևի ցանկից փոխեք **դերը** (NFR-02)։ Վերականգնման կոճակը (↻) վերադարձնում է նախնական վիճակը։

Մոդուլի վիճակը (կարգավորումներ, ճշգրտումներ, եզրակացություններ) պահվում է բրաուզերի localStorage-ում։

## Կառուցվածք

| Թղթապանակ | Բովանդակություն |
|---|---|
| `src/theme/tokens.js` | **Դիզայնի բոլոր արժեքները մեկ տեղում** (գույներ, տառատեսակներ, հեռավորություններ, բաղադրիչների ոճեր). Figma դիզայնը կիրառելիս փոխվում է միայն այս ֆայլը |
| `src/data/epd/` | EPD-ի mock՝ իրական կառուցվածքով (seed.js), դասակարգիչներ (lookups.generated.js), ընթերցման շերտ (repository.js) |
| `tools/epd-schema/` | EPD-ի կառուցվածքի արտահանում և դասակարգիչների գեներացում (միայն կարդալու, առանց անձնական տվյալների) |
| `docs/epd-schema/` | Արտահանված knowledge base, դասակարգիչներ, ագրեգատներ |
| `src/data/external/` | Արտաքին ծառայությունների mock (SRS 11.5) |
| `src/adapters/` | Ադապտերներ յուրաքանչյուր աղբյուրի համար (COM-13), mock տրանսպորտ |
| `src/engine/` | Գնահատման շարժիչ, 4.1 բանաձև, կառուցիչի արտահայտությունների լեզու, փոփոխականներ (բաժին 9) |
| `src/rules/` | Կանոններ՝ ըստ ուղղության, չիրականացված կանոնների ցանկ. `parties.js`-ում բաժին 5-ի ամբողջ քաղաքականությունը հավաքված է մեկ տեղում |
| `src/pages/` | Էջեր |
| `docs/` | [RULES.md](docs/RULES.md), [MOCK_DATA.md](docs/MOCK_DATA.md), [QUESTIONS.md](docs/QUESTIONS.md) |

Տեխնոլոգիա՝ React 19, MUI 7 (Material UI), Vite (հավաքում մեկ HTML ֆայլի մեջ)։
