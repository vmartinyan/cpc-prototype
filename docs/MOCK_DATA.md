# Mock տվյալների նկարագրություն

Բոլոր անձինք, ՀԾՀ-ները, կուսակցությունները և կազմակերպությունները հորինված են։ Փոխարժեքները հավանական են, բայց իրական ԿԲ տվյալներ չեն։

## 1. EPD (SRS բաժին 10) — `src/data/epd/`

Mock-ը կառուցված է **EPD-ի իրական կառուցվածքով**. աղբյուրներն են EPD Database Guide v1.0-ն (`docs/EPD-database-guide.pdf`)
և թեստային բազայի knowledge base-ը (`docs/epd-schema/`, արտահանված `npm run epd:schema`-ով, միայն կառուցվածք և ագրեգատներ)։

- **Աղյուսակների և սյուների անունները** համընկնում են EPD-ի հետ (`meta_field.column_name`)։
- **Տարբերակներ.** `entityid`/`instanceid`։ Ընթացիկ տարբերակը որոշվում է `de_<table>publisheditem`-ով։ Mock-ում կան նաև ոչ ընթացիկ տարբերակներ (Գայանե Սարգսյան 2025, RP-1-2025):
- **Կապեր.** section → root (`parentid` = root.instanceid), detail → section (`parentid` = section.entityid)։
- **Պրոֆիլներ.** կենդանի պրոֆիլներ (`iscloned` = 2) և կլոններ ամեն հայտարարագրի, նվերի կամ հարցաթերթիկի համար (`clonedfromprofile`)։ Ընտանիքի անդամները, ազգականները և պաշտոնները կլոնի detail տողերն են (`de_profilefamilymembers`, `de_profilerelatives`, `de_profilepositionslist`)։
- **Գումարներ.** 4 սյուն՝ `<f>_amount`, `_currencyid`, `_timestamp`, `_ratetodefault`, արժույթների id-ները՝ ըստ ուղեցույցի։ Այո/ոչ դաշտերը՝ `c_yesno` (1/2)։ Ցանկի տեսակը՝ `tabtype`։ Տողի ծագումը և կարգավիճակը՝ `datafillingoption` (1/2/3) և `status` (1/2/3)։
- **Դասակարգիչներ** (`c_*`). id-ները և անվանումները իրական են։ Դրանք վերցված են թեստային բազայից `tools/epd-schema/gen-lookups.mjs`-ով և պահված են `src/data/epd/lookups.generated.js`-ում։
- **Ընթերցում.** կանոնները տվյալները կարդում են `src/data/epd/repository.js`-ով՝ ուղեցույցի «reading recipe»-ի համաձայն։ Իրական EPD-ին միանալիս փոխարինվում է միայն այս շերտը։

Տվյալները սառեցված են (միայն կարդալու, NFR-04)։ Թեստային բազայից անձնական տվյալներով ոչ մի տող mock-ում չի պատճենվել։
